# PROJECT DARK Android

v0.45 movement/rendering vertical slice.

- Logical 4-neighbor grid projected to the original-style diagonal screen directions.
- Tap movement and four directional touch controls.
- Monster chase, targeting, attack, death and AUTO/manual override.
- Runtime samples pixels from a Nexon-hosted original Pote gameplay screenshot as a visual-reference texture layer. This is prototype/reference use only; shipping original assets require IP/license clearance.
- Placeholder actor geometry is explicit where an individually verified original sprite has not yet been cropped/mapped. No invented sprite is presented as an original asset.
