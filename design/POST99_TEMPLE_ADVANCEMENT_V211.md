신전에서 체마·EXP만으로 즉시 승급시키는 안은 ADAPTED 간소화이며 원작 그대로라고 부르지 않는다. 이번 제안은 원작 절차를 보존하고 신전에는 조건표와 준비 안내를 먼저 제공한다. 현 단일플레이에서5직업 동행을 구현하는 방법은 미결정이며, NPC 대체/1인 우회는 별도 제안이 필요하다. 과거 승급길 활성화 보류 기록도 설계만으로 해제하지 않는다.

순수 루트는 현재 직업Lv99에서 준비하며 전직 루트만 Lv1로 돌아가 재육성한다. 승급은 전직과 별개이며 일반직업 변경/레벨 초기화를 같이 실행하지 않는다. 성공 시 원작에 근거한 승급 플래그·보상 기술/장비를 정확히1회 반영하고2.5억EXP·최종 제물을 같은 거래에서 소모한다. 나머지 경험치는 보존한다. 승급 후 전직 금지는 V. 승급 후 표기레벨100 여부·능력치 구매 및 세부 보상 조건은 별도 원본 검증 대상으로 남긴다.

UI 조건표는 현재/목표/부족량을 각각 보여준다. 예: 전사 순수HP16800/17000, MP5000/5000, EXP2.4억/2.5억, 크래셔 MAX, 완전방어 미완료. 구매견적을 확보하면 체마 보충EXP와 별도 승급제물EXP를 합산한다. 과거 소비한EXP나 총누적EXP를2.5억 지불조건으로 대신하지 않는다.

## 7. 저장·실패 안전성

저장 모델: 기존normalExp 유지, purchasedHp/purchasedMp 감사 누계, baseMaxHp/baseMaxMp, advancementStage, route/jobHistory, skillMastery, promotionQuestFlags, completedRewardIds, transactionId/revision, capPolicyVersion, purchasePolicyVersion. 영구체마는 기존 durable base와 합쳐 두 번 더하지 않는다.

기존Lv99 잔액과 체마를 보존한다. 구버전 잔액이 제안 상한보다 크면 무조건 잘라내지 않고 초과 획득만 막는 grandfather 정책(ADAPTED)으로 거래/마이그레이션을 기록한다. 실제 미적립 경험치는 이력이 없으면 임의 보상하지 않고 사용자 보고를 유지한다. 모든 금액/재료/인벤토리/보상 공간 확인 후 단일 저장 성공을 기준으로 결과를 공개한다. 실패 시 전체 롤백하고 이전 저장 bytes를 보존한다. 슬롯 부족으로 바닥 드롭시키지 않는다. 중복 확정·앱 종료 시 정확히이전 또는완료 상태로 복구한다.

## 8. 구현 순서와 수락 조건

1. Lv99 문제 재현과 경로 계측: 같은 캐릭터의 몬스터 보상·퀘스트·HUD·디스크 잔액 비교. 원인 확인 후 EXP 공통 거래/상한/HUD 적용.
2. 원작 신전 공간·포탈·NPC 근거 확보와 입장/퇴장/재실행 복원. 원작 이미지·좌표 미확인 사항은 별도 기록.
3. 원작 가격표 확보 후 체마 견적·확정·영구 증가·저장. 기존 B 가격 공식 활성화 금지.
4. 직업별 승급 조건표, 기술숙련·전직/순수 상태 연결. 조건을 만족해도 미구현 승급길을 자동 통과시키지 않음.
5. 승급길 범위와5직업 동행 정책이 정해진 뒤 제물·최종승급·보상 원자적 거래.

필수 검증:98→99초과EXP,99실제처치 EXP증가,42억경계·21억초과·음수/오버플로, 구매 후 레벨99유지, 장비로 체마조건 우회 불가, 구간 경계 다회견적, 부가비용/잔액 부족 무변경, 중복 탭·저장실패·프로세스종료 복원, 기존99저장 무손실, EXP소비 뒤 캠페인 보상 재지급 불가,5직업 조건 미달/정확경계, 필수기 미숙련/제물누락/슬롯부족 무차감, 승급2회 불가, 전직/순수 경로 분리. Android 호스트 실행과 실제 휴대폰 확인을 별도 판정한다.

예산 산식: 실제99순수체마→목표체마까지 검증된 매회가격 합계 +250,000,000. 시간 산식은 동일 빌드 실측 EXP/시간으로 계산한다. 현재 구매가격과 플레이 속도를 확정하지 않았으므로 임의의 승급 소요시간을 제시하지 않는다.
