# 속성 런타임 적용 V258

2026-10-24 KST · 사용자 지시: V257 원작표 적용, 모든 몬스터 공격·방어 속성 부여 및 광산 예외 조사.

## 대미지 계산

`ElementalDamageFormula`의 행=방어·열=공격9×9 수치는 V257 첫 표 원시 대미지를 그대로 따른다. 기존 기술/기본공격의 속성 전 대미지를 기본4속성 유리 상성 대미지로 해석하고 `round(raw × 표대미지 / 18300)`을 한 번 적용한다. 양수 최소1, 정수 상한 제한. 이는 원작표를 기존 균형 수치에 연결한 **ADAPTED 정규화 선택**이며 원작 서버 원시공식 복구 주장이 아니다. 표2·3의 반올림된 정수%를 중복 곱하지 않는다. 원시표를 우선하므로 금방어×목공격은13000/18300이고, V257사진/55%기록은 보존한다.

무속성을 임의 중립1.0으로 처리하던 경로를 제거한다. 목·금·암흑·생명을 포함한81조합, 한글별칭과 LIGHT→LIFE를 지원한다. 미확인속성은 fail-neutral로 남기며 기존 고정피해·회복·상태/지속피해 계약은 유지한다. 일반 기술과 기본공격은 목걸이, 속성 마법은 그 마법의 명시 속성을 사용한다. 수동/AUTO는 같은 `CombatStatPipeline`을 공유한다.

## 몬스터 개체의 두 속성

모든 `RuntimeState.Monster`는 생성 시 공격·방어를 **각각 독립적으로** 수·토·풍·화에서 균등 추첨한다. 두 값은 같을 수도 다를 수도 있다. 일반화된 기본규칙은 사용자 지정이며 각종 모든 원작 고정속성의 확정값이라는 주장은 아니다.

살아 있는 동안 공격·피격·센스·저장 때문에 속성이 바뀌지 않는다. 성공한 리젠 시 다시 추첨하며 막힌 리젠 대기 중에는 추첨하지 않는다. 새 맵 개체군은 새 생명주기다. 기존 활성맵 선택키 `monster_elements_v258`에 ID와 두 값을 함께 저장하고 같은맵/같은ID의 유효한 자연속성 쌍만 복원한다. 구버전 저장은 새 개체의 유효 속성으로 시작하고, 잘못된값·다른맵·알수없는ID는 무시한다. 저장 schema4의 선택적 확장이며 인벤·퀘스트·보상 원자성 및 미래 schema 읽기금지 규칙은 그대로다.

광산10종중 드라코(`MINE_04`) 및 헬블씨프·헬블루나이트·헬소서러스·헬몽크·헬소서러(`MINE_05`..`09`)는 공격·방어 모두DARK다. 실제100개체 중60개체이며, 앞의 병사3종·그림록퀸은 자연속성 기본규칙이다. 현재 다른 맵에 특별 LIFE/DARK를 임의 배치하지 않는다. 광산 드라코의 과거 임시LIFE 프로필도DARK로 바로잡는다.

공통 몬스터 능력치 투영은 반드시 개체의 두 속성을 읽는다. 명시적인 불/물/뿌리 마법은 FIRE/WATER/EARTH라는 해당 행동 속성을 보존하고, 그 외 행동은 개체 공격속성이다. 센스몬스터도 동일한 두 필드를 읽으며 과거 고정프로필/특정 이름 하드코딩으로 다른 속성을 표시하던 경로를 없앤다. 캐릭터의 벨트와 `CHANGE_ELEMENT` 상태는 기존 방어 경로에서 적용한다.
