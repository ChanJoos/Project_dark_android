# 백작부인의성 V273 — 자료 분석 체크포인트

현재는 **자료 분석만 완료, 런타임 미구현**이다. 첫 영상 전체를 1초 간격으로 분해해 검토했으며 원본·타임스탬프·해시·관측 한계는 `../master/source/countess_v273/reference.json`에 기록한다.

사용자 확정 진입: 죽음의마을 대기실 경비병 → 성 외부 → 외부 NPC → 로비 → 1~12존 및 보스방. 첫 영상에는 외부/상층 응접실/2시 보스방과 보스 재등장·하이드·트랩 공략이 보인다. 공략 자막을 원작 AI 수치로 승격하지 않는다. 호러캐슬·일반 백작 별장·우딘 인스턴스의 입장료/파티/능력/재입장 조건을 혼합하지 않는다.

두 번째 `Screen_Recording_20261024_203835_YouTube.mp4`는 복구되었다(140.317056초, 2340×1080, SHA256 `1afd1d3134d7b0af0ce3c0b08aa07ce5f9a0f45994366d202a11bd3c775f8eee`). 전체 개요 2장과 보스 상세 추출본을 검토했으며 재첨부는 필요 없다. 각 존의 배치/연결/전체 몬스터/공격 모션과 원본 map/MPF ID 대조는 진행해야 한다. 정확한 source map/MPF 일치 전 임의 대체 맵·몬스터로 구현 완료를 주장하지 않는다.

맵은 타일/오브젝트/충돌/NPC/스폰/포탈 분리, 맵 생명주기 내 static navigation cache와 실제 액터 충돌, 진입 시 프레임 prewarm, 제한된 현재맵 캐시와 floor LRU32, vsync/기존 확정 저장을 보존한다. 프레임/알파/기준점을 보존하며 source로 확인된 미러링만 사용한다. 공유 Resolver·AI·장비·동료·보상 경로를 사용하고 GameView에 별도 피해 경로를 만들지 않는다.

다음 검증 범위: 경비병/외부 NPC 실제 터치·입장취소·적법 도착칸·재입장 latch, 전체 존 연결/충돌/스폰 접근, 모든 몬스터 원본 프레임/실제 공유 공격/부활, 동료 동행, 저장 재시작, 다수 액터 이동·첫공격·12회 왕복 캐시. 소스 수신 뒤 구현 파일/공유 의존성 기준으로 범위를 확정한다. 현재 새 게임 코드·빌드·APK·휴대폰 수용 없음. V272 동료 기능과 기존 수용 기준은 그대로 유지한다.
