# Canonical Data Inventory

The canonical archive preserves all 92 worksheets converted from the v4.4 workbook. Important visual/runtime sheets include `Visual_Manifest`, `Scene_Object_Mapping`, `Monster_Visual_Evidence`, `Runtime_Visual_Rules`, and `Visual_Implementation_Audit`. The archive also contains gameplay, world, NPC, monster, progression, skill, item/economy, AUTO, QA/audit and mapping data represented by the original workbook sheets.

Use the conversion manifest inside the archive for the complete machine-readable sheet inventory and validation metadata.
