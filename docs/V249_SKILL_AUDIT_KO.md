# V249 기술·마법 연결 감사

실제 카탈로그 222종을 점검했다. 222종 모두 Ability와 Action rule이 등록되어 있다. 삭제 정책 6종을 제외한 216종 중 15종은 SERVICE로 차단되어 있다. 디버그용 skill_proto/kick_proto/cast_proto 3개는 일반 카탈로그에 포함하지 않는다. 정적 등록 감사는 모든 기술의 휴대폰 실행·원작 외형 합격을 뜻하지 않는다.

## 이번 사용자 요청

속성강화와 네 직업별 쿠로토 ID는 캡처 마스킹 대신 완전한 원본 프레임/발 기준점으로 교체했다. 콘푸지오는 머리 위 별·번개 원본 한 시퀀스를 한 번 재생하며, 10초 동안 아무네지아와 같은 비선공·피해 2배 상태를 사용한다. 재시전은 상태를 갱신하며 중첩 배율을 만들지 않는다. 나르콜리는 실제 SLEEP 동안 표시되고 공격으로 잠이 풀리면 사라진다. 베노미는 실제 POISON 동안 초록 입자를 반복하며 해독·만료·사망 시 사라진다. 베노미 원작 외형은 확인하지 못했으며 완전한 원본 녹색 입자를 프로젝트용으로 배정한 ADAPTED 표현이다. 기존 독 피해량은 바꾸지 않았다.

아지토 세 ID는 모두 밀레스 여관 실내로 이동하며 저장 복원과 밀레스 여관 앞 출구를 검사했다. 클리멘스(마법사/성직자)와 로카테오는 학습·목록·사용·구 저장 퀵슬롯에서 제거한다. 이전 정의는 구 저장을 안전하게 읽기 위해 남긴다. 딜루메니/소루마는 일음지/발경의 몬스터 접촉 채널과 투영 위치를 그대로 공유한다.

## 기능 미연결 15종

| 직업 | 항목 | 현재 처리 |
|---|---|---|
| 도적 | 밀기, 적갑옷해체, 하이더, 소매치기 | SERVICE 분류로 사용 차단 |
| 성직자 | 로카메아, 리치마나, 소모니아, 디노센스 | SERVICE 분류로 사용 차단 |
| 공통 | 수영, 노점개설, 채집, 낚시, 일반제조, 아이템고치기, 마나스페라 | SERVICE 분류로 사용 차단 |

수혈은 별도 상태 정의가 있지만, 단일 플레이에 그룹 수혈 대상이 없어서 정상 시전이 거절된다. 자신에게 HP를 옮긴 것처럼 처리하지 않는다. 코마디아 역시 현재 단일 플레이 자기 HP 보정 경로와 실제 그룹 부활 콘텐츠를 동일시할 수 없다.

## 간이 서비스와 원작 미확정 부분

품뒤져보기·센스·센서스·탐색·아들레스투는 현재 기본 대상 HP/MP 정보 경로다. 원작의 각각 다른 정보 조회 전체를 구현했다는 의미가 아니다. 문열기·자물쇠열기는 인근 상호작용 NPC 경로이며 별도 잠금/자물쇠 시스템은 없다. 유즈스태프는 안내 경로이고 별도 지속 상태를 만들지 않는다. 함정찾기/해체 계열은 로컬 함정 목록을 검사하며 모든 맵의 원작 함정/보물상자 콘텐츠가 연결된 것은 아니다.

## 이펙트

마법사 아마게돈·숨마스텔라·데스는 기능이 있지만 현재 프로젝트 대체 이펙트를 사용한다. 정권·블레스·홀리쇼크와 현재 사용할 대상이 없는 수혈도 감사상 PROJECT_FALLBACK이다. 기존 승인된 무도가 표현은 이번 작업에서 임의로 변경하지 않았다.

아지토와 도구/정보 서비스는 공격 피격 이펙트를 만들지 않는다. 기본공격·이형환위·센스몬스터·연계/패시브는 전용 몸동작/창/공격 경로가 있으므로 공통 대상 이펙트가 NONE인 것만으로 누락이라 판정하지 않는다. 캡처 기반/공유 소스가 존재하는 나머지 항목도 원작 프레임·색·템포·휴대폰 외형 전체가 승인됐다고 주장하지 않는다.

전체 기계 판독 결과: `verification/STATUS_MAGIC_V249_SKILL_AUDIT.json`. 실행·원본 픽셀·APK 증거는 `verification/STATUS_MAGIC_V249_BUILD.json`에 기록한다.

검증 범위: 최종11검사 + 코드 변경이 없는 인접29검사 재사용 =40건. 수면 전 프레임/몸 높이16·46·90 검사 통과. 추가 Death 몬스터 캡처는 실제 지하 배경 진입 fixture가 빠져 밀레스 배경에 해당 종을 표시하므로, 지하 맵 전체 화면 검증으로 표기하지 않는다. 휴대폰 수용은 미완료다.
