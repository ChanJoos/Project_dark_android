# 포테의 숲 A·B·C 성장 / D 보스 기획

상태: **구현 완료 후보 · V111 CI/APK 검증 진행 중 · 실기기/사용자 시각 확인 대기** · 기준 소스: V110 merge `00b094c76add19d7c5fc1292365cf208882bf3a5` · 작업 브랜치 `codex/pote-abcd-lv11-41`

## 목표

V110 초보 교육 뒤 A01 숲 등록 보상으로 Lv11에 도달하고, 사냥터 A→B→C를 거쳐 Lv40이 된다. 준비 의뢰 후 별도 맵 D의 자이언트맨티스를 처치해 세줄금반지와 Lv41을 받는다. 사냥 맵마다 지형과 몬스터 구성을 구분한다. 강력형 몬스터는 사용하지 않는다.

## 지역과 몬스터

| 지역 | 성장 구간 | 일반 몬스터 | 구성 의도 |
|---|---:|---|---|
| A 입구 숲 | 11–19 | 레드·그린·퍼플·실버 팜팻 | 색상별 표본과 개울 주변 탐색 |
| B 무리 숲 | 20–29 | 트렌트·앤트라이온·놀·라이칸스로프 | 나무뿌리/모래 서식지와 무리 추적 |
| C 깊은 숲 | 30–40 | 울프라이더·앤트자이언트·은빛늑대, 원본 확인 후 갈색/검은 정령 | 경계길, 벌레 둥지, 늑대 영역, 결계 조사 |
| D 결계 너머 | Lv40 보스 도전 | 자이언트맨티스 1마리 | 준비·전투·첫 클리어 보상. 일반 반복 사냥터로 쓰지 않음 |

갈색/검은 정령은 이번 성장 경로에 넣지 않는다. A/B/C의 11개 일반종은 모두 4방향 대기·이동·공격 포즈를 연결했다. D의 맨티스도 새 투명 4×3 시트에서 12개 포즈를 분리해 런타임에 연결했다. 이는 원본 게임 스프라이트가 아닌 신규 생성 ADAPTED 후보이며, 프롬프트/시트/파일별 SHA-256을 보존했다. HP 3200·공유 AI·보상 경험치 0은 밸런스 검증 전 설정이다. 사용자 시각 수용과 실기기 확인은 별도 대기한다.

각 지역의 맵 경계·이동 격자·장애물·지형 경로·시각 배치·스폰 구역·포탈 도착 지점은 `PoteCampaignMapDef`와 지역별 geometry/placement로 분리한다. 기존 원본 에셋을 재배치한 ADAPTED 구성이다. 피에트 야영 기능은 안전 거점으로 유지하되 네 번째 사냥터로 세지 않는다.

## 필수 구현 순서

1. **맵 기반**: 맵별 `MapDef`/geometry/render/collision/spawn pockets/portal을 분리하고 A/B/C의 서로 다른 지형을 만든다. 옛 `MAP_PIET_CAMP`, `MAP_POTE_01–04` 저장을 안전하게 마이그레이션한다. 이전 `MAP_POTE_04`를 새 보스맵으로 오인하지 않는다.
2. **몬스터 연결**: 현존 11 일반종을 표의 사냥터에 배치한다. 갈색/검은 정령은 identity/pose 자료 확인 전 제외한다. 맨티스는 별도 D 맵 보스로 연결하고, 방향별 12포즈 생성 후보를 런타임에 등록한다. 강력형은 새 성장 경로에서 제외한다.
3. **성장 퀘스트**: A/B/C/D 의뢰, giver/objective/turn-in 위치, 저장 가능한 각 목표 이벤트, 레벨 잠금/해금, 퀘스트 추적 UI를 구현한다. 기존 퀘스트 보상과 중복 지급되지 않게 버전 마이그레이션한다.
4. **보스/정산**: 정상 Lv40 장비·2써클 기술의 다섯 직업 솔로 전투를 시험한다. 보스 첫 처치, 부족 EXP, Gold, 선택 보상, 퀘스트 완료를 한 번만 정산하고 저장 실패 시 보류 보상을 복구한다.
5. **검증**: 다섯 직업의 Lv11부터 D 완료까지 실제 경로, 맵 간 이동, 스폰/충돌/AI, 퀘스트 재접속, 저장 마이그레이션, 패키징 아트를 검증한다. 테스트 빌드 통과와 실기기/사용자 시각 확인을 별도 보고한다.

## 현재 구현 상태

- 새 저장은 V110 도입부 뒤 M06 출정 준비와 A01–D04 28개 숲 의뢰를 사용한다. M06이 Lv10/300,000 EXP 상태에서 Lv11까지 부족한 경험치를 지급하고, A01은 Lv11 입장/등록이다. M03을 끝낸 v1–v3 저장은 완료한 옛 M06 이후 의뢰를 안전하게 새 완료 ID로 옮기고 진행 중인 변경 목표는 초기화한다. 목표 이벤트는 기존 처치/방문/레벨/제단 런타임에 연결했다.
- 이전 저장 위치 `MAP_POTE_04`는 별도 호환 맵으로 남겼다. 새 결계 보스 맵 ID는 `MAP_POTE_D_BOSS`이며 이전 ID를 재해석하지 않는다.
- A/B/C에 일반 몬스터 4/4/3종을 분배했다. 강력형과 정령은 새 경로에서 제외했다.
- D는 맨티스 단일 보스와 D03 처치 의뢰를 포함한다. 첫 D03 완료는 세줄금반지를 직접 인벤토리에 한 번 지급하고, 부족 EXP와 퀘스트 완료를 같은 저장 트랜잭션에서 반영한다. 원본 몬스터 드롭 연결을 모바일 직접 보상으로 바꾼 ADAPTED 보상 방식이다. 맨티스의 12개 방향/상태 스프라이트는 연결됐으며, 다섯 직업 전투/기기 시각 검수와 CI 빌드는 미완료다.
- 퀘스트 turn-in은 기존 저장 트랜잭션에서 경험치/아이템/완료 기록을 함께 반영한다. D03 turn-in의 경험치 보정 목표는 Lv41이다.
- `git diff --check`와 `python3 tools/validate_master.py` 통과. 새 `verify_v111_apk.py` 및 CI에 A/B/C/D, 진행, 12개 맨티스 포즈 검증을 추가했다. 로컬에 Gradle 실행기와 wrapper가 없어 Android 테스트/APK는 원격 CI로 검증해야 한다. 실기기/사용자 시각 확인은 CI 결과와 별도로 남는다.
