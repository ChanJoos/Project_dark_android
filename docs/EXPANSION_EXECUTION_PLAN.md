## 추가 던전과 후속 순서

밀레스 지하묘지 10~17층·언데드/소환석/보물상자 체인은 Quest_Runtime_Master에서 Lv40~60 범위로 남아 있다. 아벨 주 성장 루트를 임의 대체하지 않고 같은 레벨대 선택 던전 묶음으로 둔다. 최초 성장표 P00의 초반 지하묘지 배치와 최신 Lv1~40 계획의 후속 던전 결정이 충돌하므로 후자를 보존한다.

아벨 묶음 뒤 P05/P06 뤼케시온, P07 마인·호러캐슬, P08~P11 순수/전직/승급 순서로 진행한다. 각 묶음은 지역만 추가하지 않고 몬스터·보스·드롭·직업 스킬·장비·보급·저장까지 한 플레이 흐름으로 닫는다.

## 필수 보호와 미확정 서비스

- 승인 B HUD, 10개 스킬 원본 픽셀, 4대각 이동/공격, 공격 후 방향, BODY/장비 결합, 인벤토리 오버레이, 직접 자동 획득을 유지한다.
- 신규 사냥맵은 docs/HUNT_MAP_PERFORMANCE_LESSONS.md의 indexed-map/pathfinding/static-floor-cache/live-collision/prewarm/vsync/save 계약과 12회 왕복·p95/p99/max·캐시 검증을 적용한다. 해상도·개체수 저하로 통과시키지 않는다.
- 신규 몬스터 제작은 docs/MONSTER_CREATION_MANUAL.md를 따른다. 원작 참조/승인 스타일/앵커를 실제 런타임 크기에서 함께 검수한다.
- V138의 21개 unavailable 경로 전부를 먼저 끝내야 확장 가능하다는 조건은 만들지 않는다. 새 지역의 필수 의존성(이동/귀환·필요한 회복/해제·보스 조건)만 해당 티켓에 연결하고 없는 서비스는 성공한 척하지 않는다.
- 5직업 파티를 전제로 한 후속 보스/승급은 로컬 대체 설계 또는 서버 단계가 필요하다. 기존 Master 파티 조건을 조용히 삭제하거나 더미 NPC로 온라인 완료라고 주장하지 않는다.
- 원작 미확정 보상·공식·스킬 시전·몬스터 외형은 미확정으로 유지한다. 새로운 자산/모바일 조정은 원본과 별도 변경 기록을 둔다.
