# PROJECT DARK — 평민 시작부터 2써클 완료까지

2026-10-04 · 찬님 요청 기획안 v1 · 상태: PROPOSED / 미구현

목표는 새 캐릭터가 게임 안의 안내만으로 직업을 얻고, 해당 직업의 장비와 기술을 갖춰 레벨 40까지 성장하는 완결된 경험이다. 퀘스트를 마친 뒤 다음 목표가 사라지거나, 몬스터를 잡아도 경험치가 오르지 않거나, 돈·마나 부족으로 진행이 막히는 상태를 완료로 인정하지 않는다.

## 1. 현재 상태와 근거

검토 기준은 활성 브랜치 `codex/town-interiors-mobile-v86`, 문서 포함 SHA `5434d9cb880ff2966fc97d8a95be3a6f88653938`다. 실제 전달 APK는 V104, 런타임 SHA `48f8a037872c8ddfab8abacd5808671de9dd9f8f`다. 이 문서는 게임 코드나 APK를 변경하지 않는다.

| 구분 | 현재 확인한 상태 | 이번 기획에서 필요한 변경 |
|---|---|---|
| 시작 | 평민 Lv1, STR/INT/WIS/CON/DEX 각 3, Gold 0 | 시작 장비·보급·안내 보장 |
| 직업 | `currentJobCode=COMMONER`; 최초 직업 선택 장소·진행이 없음 | 직업 상담, 체험, 선택, 저장, 직업 장비 지급 |
| 퀘스트 | 여관의 소란, 성장 훈련, 숲 이동 안내까지 플레이 가능 | Lv40까지 이어지는 실제 상태·목표·보상·동선 |
| 포테 보상 | 일반 몬스터 대부분 보상 미해결; 경험치 지급 안 됨 | 몬스터별 프로젝트 보상과 생성 개체 연결 |
| 성장 | Lv1→40 필요 누적 EXP 9,000,000; 레벨당 스탯 포인트 2 | 이 곡선에 맞는 EXP 공급·전투시간·스탯 안내 |
| 상점 | 밀레스 거래·은행·성당 서비스 구현, 일부 기본 장비 판매 | 직업별 상품, MP 보급, Lv11/26 교체 동선 |

| 미래 의뢰 | `quests/journal.json`의 후속 항목은 모두 LOCKED | 표시용 목록과 실제 실행 가능 의뢰 분리 |

근거의 강도를 섞지 않는다. 사용자 확인 사항은 U, 넥슨 공식 확인은 O, 기존 Master의 출처 있는 자료는 해당 V/FAN 등을 유지한다. 이 문서의 최초 직업 레벨·보상·사냥 수치·가격·신규 퀘스트는 B/ADAPTED 제안이다. Master에 이름이 있는 아이템도 능력치·가격·원본 이미지까지 검증됐다고 간주하지 않는다.

기존 자료의 충돌을 먼저 정리한다.

- `Quest_Placement.csv`는 지하묘지를 1~2써클로 분류하지만 `Quest_Runtime_Master.csv`의 구체 의뢰 권장은 40~58 및 45~60이다. 이번 Lv1~40 필수 경로에 원작 지하묘지 체인을 넣지 않는다. Lv40에서 다음 이야기 안내만 노출하고 실제 도전은 41 이후로 배치한다.
- `Q_POT_01`의 포테의 정령은 `Monster_Master`/`PoteMonsterRoster`상 Lv48, HP29,201, EXP308,950이다. Lv40 이전 필수 보스로 축소·변조하지 않는다. 팜팻 변화 조사 전반과 후반 정령 의뢰를 분리한다.
- 공식 2025-05-22 업데이트는 1~5써클 기술 학습 재료·Gold 제거, 초반 의뢰·몬스터 경험치 변경을 설명한다. 기존 프로젝트는 학습에 금전/재료를 쓰는 별도 모바일 정책이므로, 이를 현행 원작 가격이라고 부르지 않는다. 본안은 필수 기술 무료, 선택 기술 유료를 제안한다.
- 기존 모바일 기술 계약은 직업·레벨 잠금을 적용하지 않는다. 아래 직업별 정상 진행 정책은 그 계약에 대한 변경 제안이며, 구현 승인 전까지 현재 정책을 덮어쓰지 않는다.

## 3. 직업을 얻는 장소와 절차

### 공간과 NPC

밀레스 서부 서비스 구역의 기존 비입장 주택 한 채를 **직업 상담소**로 전환한다. 문과 포탈을 정확히 붙이고 기존 마을/상점과 동일한 World 좌표·이동·충돌·깊이·카메라를 사용한다. 건물을 과밀하게 추가하지 않는다. 상담실의 중앙 접수와 다섯 훈련 구획은 겹치지 않는 타일에 배치한다.

### 최초 직업 선택

해금 조건은 **Lv3 이상 + 성장 훈련 완료**다. Lv3은 원작 최초 직업 레벨을 확인한 값이 아니라 프로젝트 제안이다. 현재 두 퀘스트 후 약 Lv3에 도달하며, 기본 마법 학습 스탯에도 최소 4포인트가 필요한 점을 반영했다.

1. James가 직업 상담소를 다음 목표로 지정한다.
2. 다섯 직업 카드에 공격 방식, 거리, 주 능력치, 소모품 부담, 솔로 플레이 예시를 보여준다.
3. 직업당 20~30초 체험을 선택적으로 제공한다. 체험 장비·기술·HP/MP는 임시이며 보상·아이템·숙련도는 남기지 않는다.
4. 지도자에게 말을 걸어 기본직업을 선택한다. 전직 비용·희귀 재료·랜덤 합격 조건은 없다.
5. 직업 코드 변경, 입문 의상·무기/격투 장구·첫 기술·보급 지급, 퀘스트 완료를 한 번의 저장 거래로 처리한다.
6. 장비창과 기술창에서 지급품을 확인하고 첫 기술을 퀵슬롯에 배치하는 짧은 실습을 진행한다.

이 흐름은 **최초 기본직업 선택**이다. Lv99의 전직·순수직업 선택·승급과 별개이며 고레벨 규칙은 변경하지 않는다. 일반 플레이에서 자유로운 재선택을 제공하지 않는다. 다섯 직업 검수는 별도의 새 캐릭터로 한다.

전직 후 스탯 추천은 강제 자동 분배가 아니다. 시작 직업에 필요한 스탯을 보여주고 확인받는다. 이미 잘못 투자한 초반 포인트는 최초 직업 선택 시 1회 무료 재배분을 제안한다. CON/WIS에 따른 HP/MP 성장 효과를 설명하고, 재배분 시 성장 재계산 정책·저장 거래·중복 방지를 명시해야 한다. 역사적 성장량을 알 수 없는 저장을 임의 역산해 덮어쓰지 않는다.

## 4. 직업별 플레이·장비·기술

| 직업 | 전투 경험 | 입문 지급 | Lv11 보장/판매 | Lv26~40 업그레이드 후보 | 중요한 재화·소모품 |
|---|---|---|---|---|---|
| 전사 | 인접 타격, 체력으로 버티며 연속기 | 레더튜닉/튜닉 + 입문 검 | 지폰/레데메일, 토마호크 또는 타고나이트액스 | 하프플레이트/미스티플레이트, 구리방패; 무기는 신규 검증 필요 | HP약, 무기·갑옷 구매 금전 |
| 도적 | 근접 찌르기와 원거리 표창, 타깃 선택 | 스카웃튜닉/꼬뜨 + 비설표 | 노미쉬레더/브리간딘, 비중표 | 채찍 Lv26 후보; 표창과 장비 슬롯 관계 검증 | HP약, 표창 장비; 반복 소모 탄약은 본안에서 요구하지 않음 |
| 마법사 | 거리 유지·속성 선택·MP 관리 | 후드로브/매직스커트 + 입문 지팡이 | 달마티카/베누스타, 매직스태프 | 매직새티아 Lv15 → 매직루나 Lv25 | MP약, 로브·지팡이, 선택 기술 수련비 |
| 성직자 | 공격 마법 + 자기 회복, 정화 보조 | 셍즈/로브 + 홀리완드 | 레더로브/미스틱로브, 홀리루나 | 회복·정화 기술, 산호귀걸이·고루반지 | MP약, 정화 의뢰 재료; 필수 기술 재료 무료 |
| 무도가 | 무기 없이 주먹·발차기, STR/CON 균형 | 도복/연무복 + 실제 격투 기본공격 | 단도복/연무도복, 가죽팔찌 | 각반·신발·팔찌 개선; 상위 도복 ID는 검증 후 선정 | HP약, 방어구·팔찌 구매 금전 |

표의 실제 아이템 이름/요구 레벨은 `Item_Master.csv` 후보를 사용했다. 입문 검·입문 지팡이·무도가 후반 팔찌는 프로젝트 임시 정의 또는 원본 확인이 필요한 항목이다. 원본 이름·ID가 없는 상위 장비를 임의로 원작 아이템처럼 등록하지 않는다. 동일 장비의 남녀 복장 차이는 슬롯과 성능을 바꾸지 않으며, 두 BODY 모두 실제 착용·행동 검수가 필요하다. NPC가 입은 고레벨 장비를 저레벨 플레이어 보상으로 자동 재사용하지 않는다.

### 장비 지급과 구매의 균형

- 직업 선택: 입문 의상·전투 수단 무료, 첫 HP/MP 보급 무료. 인벤토리 부족 시 지급함/보상 대기 상태로 보존하고 직업만 바뀌는 부분 성공을 막는다.
- Lv11: 직업 의상 또는 핵심 무기 중 **하나**를 선택 보상. 나머지는 사냥·금전으로 구매한다. 무도가에게 무의미한 검 보상을 주지 않는다.
- Lv15~20: 가죽장갑/각반/신발, 귀걸이·반지 중 역할에 맞는 구매 목표. 반지 두 슬롯을 어떻게 처리하는지는 기존 슬롯 모델과 대조한다.
- Lv26: 다음 직업 주력 장비 하나를 선택 보상, 나머지는 피에트 보급점에서 구매. 물리 직업은 쌍금귀걸이 후보, 마법 직업은 산호귀걸이 Lv25 후보를 안내한다.
- Lv36~40: 모든 슬롯을 채우는 것을 완료 조건으로 강제하지 않는다. 필수 전투 성능을 갖춘 상태에서 선택 장신구·속성 장비를 추구하게 한다.
- 장비 변경 전후 FinalStats와 실제 피해/회복을 함께 검증한다. 방패 가능 직업은 확인된 제한만 적용하고 무도가의 격투와 방패가 부자연스럽게 동시에 표시되지 않게 한다.

### 기술 단계

핵심 기술은 진행 퀘스트 보상 또는 조건 만족 후 무료 학습으로 제공한다. 레벨은 안내 시점이고 최종 학습 가능 여부는 해당 스킬의 확정된 조건/프로젝트 정책으로 검증한다. 미구현 기술을 명칭만으로 보상 지급하지 않는다.

| 직업 | 최초 직업~Lv10 | Lv11~25 | Lv26~40 |
|---|---|---|---|
| 전사 | 숏블레이드 | 더블어택 | 윈드블레이드; 트리플어택은 조건 충족 가능성부터 검증 |
| 도적 | 찌르기 | 표창 공격, 찔러휘비기 | 더블어택·인식 교란 후보; 실제 행동 지원 시만 활성화 |
| 마법사 | 마레노 | 타 속성 단일 공격 | 2써클 범위 공격; 여러 대상 실제 판정 필요 |
| 성직자 | 쿠로 + 입문 솔로 공격 보장 | 홀리쇼크·쿠라노 | 해독/저주 해제·보조; 쿠라네라는 Master상 4써클이므로 제외 |
| 무도가 | 정권 | 단각 | 양의신권·통배권; 추가타/지속 피해를 실제로 구현 |

성직자: 홀리쇼크는 자료상 2써클 공격이다. Lv3부터 이를 원작 스킬인 양 조기 지급하지 않는다. Lv3~10에는 **프로젝트 입문 성스러운 타격** 또는 완드 기본공격으로 솔로 성장시키고 Lv11에 홀리쇼크로 연결한다. 입문 공격은 프로젝트 전용 ID·설명이며 Master 원본을 오염시키지 않는다. 홀리쇼크의 실제 피해·시전·MP·원거리 접근을 필수 개발 항목으로 둔다.

마법사: 현재 모바일 마레노 조건 INT6/WIS4를 그대로 쓰면 기본값3에서 4포인트가 필요하다. Lv3의 4포인트를 INT+3/WIS+1로 배분하면 학습 가능하지만 체력 투자 여지가 없다. 이 경로는 안내하고 실전 생존을 장비·회복으로 보장한다. 첨부 자료의 INT4/WIS4와 현재 모바일 정책의 INT6/WIS4 차이는 정책 변경 제안으로 따로 기록한다.

전사: 더블어택 STR16/CON10은 기본값3에서 20포인트로 Lv11에 가능하다. 윈드블레이드 STR32/CON24는 50포인트로 Lv26에 가능하다. 트리플어택 STR46/CON40은 80포인트가 필요해 Lv40의 78포인트만으로 불가능하다. 스탯 보너스 장비를 필수로 확보시키거나 후속 구간으로 넘겨야 하며 본안 필수 경로에서는 제외한다.

모든 직업의 추천 분배는 Lv1~40 총 78포인트를 넘지 않아야 한다. 성장용 CON/WIS와 기술용 스탯 사이의 선택을 안내하고, 필수 기술이 잘못된 분배 때문에 영구적으로 막히지 않도록 1회 교정 경로를 둔다. 다른 직업으로 습득한 기존 기술 기록은 삭제하지 않는다. 정상 모드에서 직업 제한을 도입하려면 기존 저장 호환·과거 사용자 계약 변경을 검토한 후 적용한다. 시험 모드는 정상 플레이와 분리한다.

### 반복 의뢰

지역별 게시판에 동일 구역 10회 처치 또는 잡템10 판매 의뢰를 둔다. EXP 보너스는 해당10회 일반 사냥 EXP의 최대10%로 제안한다. 10분 단위 추천 갱신, 동시 수락1개, 일일 횟수 제한은 없다. 일회성 스토리와 독립이며 로그인 날짜·시간 변경으로 보상이 복제되지 않아야 한다. 반복 보너스는 아래 9M 기본 예산에 포함하지 않았으므로 사냥 횟수/시간을 줄이는 보조 수단이다.

## 6. 경험치 공급과 사냥 설계

기존 곡선은 그대로 두고 일회성 퀘스트40%, 일반 사냥60%를 초안으로 배분한다. 총 일회성 EXP3,600,000, 사냥 EXP5,400,000이다. 보스·실습·수집 과정 처치는 사냥 몫에 포함한다.

| 포테4 후반 | 정예 개체/제단 주변 강력 개체 | 48,000~56,000 | 일반16~24초, 정예40~60초 |

수치는 원작 EXP로 주장하지 않는 B 초안이다. HP·AC·명중·공격·MP 소비·인식 반경은 각 직업 실제 장비와 스탯으로 역산한다. 같은 몬스터 이름에 레벨 구간별 임의 EXP를 덮어쓰지 않고, 일반/강력/프로젝트 정예 각각 명확한 개체·보상 프로필 ID를 둔다. 포테의 정령의 기존 원본 수치는 그대로 보존한다.

현재 `PotePrototypeRewardBoundaryAudit`는 미확인 원작 보상을 지급하지 않는 것을 검사한다. 이를 삭제해 임의 값을 canonical 보상에 넣지 않는다. 프로젝트 진행용 보상 정책을 별도 등록해 명시적으로 선택한 개체에만 적용하고, 미등록 canonical 보상은 계속 미해결로 남긴다. 새로운 정상 진행 보상은 별도 테스트로 실제 EXP/Gold 증가와 재시작 중복 방지를 증명한다.

사냥터는 처음 두 구역에서 근거리 안전 지점과 단일 몬스터 접근을 보장한다. 3~4구역부터 작은 무리·해독 가능한 상태 이상·공격 예고를 추가한다. 리젠은 일반20~30초, 혼잡 시 빈 사냥터가 생기지 않는 개체 수로 조정한다. 보스/의뢰 개체는 진행자별 보장 스폰 또는 처치 공헌 공유를 사용해 다른 플레이어 때문에 영구 대기하지 않게 한다. 멀티플레이 미구현 단계는 로컬 단독 조건으로 검증한다.

## 7. 재화·드롭·가격

핵심 화폐는 **Gold 하나**다. 직업별 새 전용 화폐 다섯 개를 만들지 않는다. 차이는 지출처·장비·보급에 둔다. 조사 정수·서신은 퀘스트 아이템이며 거래/판매가 불가하다. 훈련 증표는 기존 데이터와 호환하되, 추가 성장 화폐로 확장하지 않는다.

수입은 처치 Gold + 일회성 의뢰 Gold + 일반 잡템 판매로 구성한다. 장비 희귀 드롭과 반복 의뢰 보너스는 선택 수입으로, 필수 진행 예산에서 제외한다. 모은 퀘스트 재료를 모르고 팔아 경로가 막히지 않도록 자동 잠금한다.

구역 번호는 원작 정확한 전체 지형 복구를 뜻하지 않는다. 모바일 진행을 위한 ADAPTED 지도다. 포탈은 문/숲길 경계에 붙이고, 입장·귀환 타일이 오브젝트/몬스터/다른 포탈과 겹치지 않게 한다. 자동 이동은 현재 맵 경로뿐 아니라 다음 포탈→다음 맵→다음 NPC/목표의 순서를 이어야 한다. 모든 구역에서 원작풍 톤·간격·나무 가림·강/다리 통행을 검수한다.

속성 장비는 원작 명칭/관계가 확인된 것만 설명한다. 4속성 목걸이·벨트는 선택 판매로 두되, 확정된 전투 속성 계산과 맞물린 의뢰에서만 사용을 가르친다. 단순히 특정 벨트를 안 샀다는 이유로 40레벨 경로를 막지 않는다.

## 9. 퀘스트·UI·저장 규칙

- 퀵퀘스트는 현재 위치에서 바로 할 일 하나를 보여준다. 진행0/10, 보고NPC, 다음 장비/기술 점검을 간단히 표시하고 탭하면 해당 목표로 이동한다.
- 퀘스트창은 수락가능/진행/보고/완료/잠김을 실제 도메인 상태로 표시한다. 잠김 이유는 정확한 미달 레벨·선행 의뢰·미개방 맵이다. 자료용 미래 의뢰는 진행 가능한 의뢰와 혼동하지 않게 한다.
- 경험치·Gold·아이템 처치 보상은 별도 피드백에 모두 보이고, 아이템 알림 때문에 EXP가 숨지 않게 한다. EXP바/현재레벨/레벨업포인트가 즉시 갱신된다.
- 실습·수집은 `combat event ID`, `spawn instance ID`, `quest step ID`, `reward transaction ID`로 중복을 막는다. 몬스터 종 ID만으로 모든 리젠을 한 번으로 간주하지 않는다.
- 퀘스트 상태·개수·정수·직업·장비·기술·Gold·EXP·레벨·스탯·맵/복귀 타일을 일관된 체크포인트로 저장한다. 보고와 지급 사이에 앱을 종료해도 보상이 한 번만 지급돼야 한다.
- 업데이트 시 기존 두 퀘스트 완료·기술 습득·장비·금전을 유지한다. 옛 캐릭터가 평민인 경우 다음 상담 의뢰를 노출한다. 새 직업 제한으로 기존 기록을 삭제하거나 이미 쓴 금전을 다시 차감하지 않는다.
- UI 스탯 표기는 STR/INT/WIS/CON/DEX를 유지한다. 퀘스트·상점·NPC는 기존 UI 톤과 타깃 크기를 유지하고 내부 구현 설명을 플레이어에게 노출하지 않는다.

### 필수 검증 시나리오

1. 새 캐릭터는 평민 Lv1로 시작하고 기존 BODY·이동·공격·카메라를 유지한다.
2. 두 기존 퀘스트 완료 후 상담소까지 자동 안내된다. 임시 체험을 종료해도 원래 캐릭터에 시험 장비·스킬이 남지 않는다.
3. 다섯 직업 각각 별도 정상모드 캐릭터로 플레이한다. 테스트용 무한MP·전체 기술·EXP 강제 주입을 성장 완료 증거로 쓰지 않는다.
4. EXP 미등록 진행 몬스터가0개여야 한다. 일반/정예/리젠/다중타격/앱재시작에서 보상 중복0이다.
5. 포션·금전·인벤토리 최대/부족·스탯 오투자 상황에서도 회복·교정·재취득 경로가 있다.
6. 필수 구입 직전 실제 최소 소지금과 가격을 비교한다. 직업별 MP·HP 소비와 보급을 포함한 잔액이 음수가 되는 경로가 없다.
7. 레벨·직업·장비·기술 변경이 표시만 바뀌지 않고 실제 피해·회복·명중·자원에 반영된다.
8. 팜팻 조사·정화·정예 전투가 실제 맵에서 가능하며 지역 이동 후 목표NPC/개체를 찾을 수 있다.
9. 40레벨 도달 후 완료 보고가 가능하고 원작 Lv48 정령·Lv45 지하묘지 후반 의뢰를 강제하지 않는다.
10. 네 방향·야외/실내·5직업·남녀 BODY·나무앞뒤·다리·문·벤치·성당을 실제 화면에서 일괄 검수한다.
11. 게임 종료·강제중단 후 해당 직업/레벨/Gold/EXP/기술/장비/의뢰 단계/현재 맵이 복원된다.
12. 빌드/자동실행/실기기/사용자 시각 승인을 각각 보고한다. 개발용 도메인 시뮬레이션만으로 휴대폰 2.5시간 클리어를 주장하지 않는다.

완료 정의는 **게임 내 안내만 따라 다섯 직업 각각 정상 플레이로 Lv40에 도달하고, 필요한 장비·기술·소모품을 확보하며, 마지막 보고와 저장·재시작이 가능한 상태**다. 보기 좋은 NPC·퀘스트 목록·맵 캡처만으로 성장 콘텐츠 완료라고 보고하지 않는다.
