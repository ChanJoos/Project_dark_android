현재 아벨 해안13개 런타임ID 전체를 검수했다. 퐁퐁이·애벌레·터틀·아크퍼스·회청색·문어·튜터7종84프레임을 원작 참조로 재구성한다. 나머지 그래브·보라·가스·광폭자·가짜/진짜킹아크퍼스6ID는 기존 해부형상 적합성/크기를 검수했다. 그래브·가스·광폭자는 실제 알파 경계를 별도 보정. 기존 그림의 단순 확대가 아니다.

기준 master/source/abel_v161/calibration.json: 같은 영상 프레임의 캐릭터 높이에 대한 몬스터 폭/높이 관측치와 source crop을 보존한다. 투명192캔버스의 폭/높이를 곧 실제 몸체 크기로 취급하지 않는다. 목표 투영 기준52px와 실제 native 캐릭터 알파 높이54px를 구분하며, 실제 비율은 receipt의 V161_NATIVE_RATIO로 검수했다. 수동 관측 및 투영에는 허용오차가 있다. 모든 방향/동작은 생성 재구성, 원작 atlas/원본 프레임이 아니다.

13ID별 판단은 calibration.rows.review. 킹아크퍼스 원작은 나무/캐릭터에 가려져 정확한 비율과 진짜/가짜 시각 구분은 UNRESOLVED; 현행 거대 후보 유지. 보라 부유체도 명확한 같은 캐릭터 계측이 없어 기존 크기 유지. 슬러그/에스코모이드는 옛 아벨 던전 자료이며 해안 배치 미확정이므로 새 해안 종으로 발명하지 않는다.

현재 첨부18개 JPEG/GIF는 실제로 열어 확인했으며 기술표/이펙트 자료다. 몬스터 대조는 이전 사용자 제공 원작2영상과 저장소의 원작crop을 사용했다. 뤼케시온10종의 사용자 승인 그림/크기/팔레트/모션은 보존한다.
