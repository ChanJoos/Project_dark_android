원작에 최소 15번 방이 존재한다. 13번이 마지막이라는 전제는 폐기하며, 15번이 마지막인지는 미확인이다. 백작의 별장 층수 검색 결과는 다른 사냥터이므로 호러캐슬 방 수 근거로 쓰지 않았다.

03·04·05·07·09는 기존 원본 6403·6404·6405·6407·6409 배치를 보강한다. 13·14·15는 방 번호와 보이는 가구 배치를 확인하는 부분 자료다. 가려진 구역, 전체 크기, 충돌, 문 연결은 이 캡처만으로 확정하지 않는다. 원본 맵 바이트는 12–15 모두 미확보다. 기존 한국/미국 맵 후보에 비슷한 가구가 있다는 이유로 다른 방을 복제하지 않았다.

원본 JPEG 10장을 수정 없이 ZIP에 보관하고 개별 SHA-256을 JSON에 기록했다. 이번 변경은 근거 자료와 진행 상태 수정이며 런타임 맵·전투·세이브를 변경하지 않았다. 기존 구현에는 아직 13번 이후 로비로 돌아가는 동작이 남아 있으며, 이를 원작의 종료 지점이라고 간주하지 않는다. 구현 변경이 없어 기존 전투 테스트나 APK 빌드를 재실행하지 않았다.
