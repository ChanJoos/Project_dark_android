# 밀레스 공간 배치 기준

원작을 복사한 지도 대신 원작 화면에서 관찰한 **물체의 관계**를 새 밀레스에 적용한다. 원작 두 장면의 촬영 시점과 UI 비율을 새 게임의 세계 좌표나 실제 건물 위치로 취급하지 않는다.

| 화면 근거 | 관찰된 관계 | 새 마을에서의 적용 |
|---|---|---|
| 원작 밀레스 마을 영상 `163242`, 2초 | 분수는 잔디 휴게 공간의 중심이고 벤치는 길 바깥에 모여 있다. 등과 나무가 쉼터를 두른다. | `civic_fountain` 주변 벤치·나무·표지판을 같은 쉼터로 묶고 벤치는 통행 폭 밖, 길에서 105 좌표 이내에 둔다. |
| 같은 영상, 7–12초 | 흙길은 녹지 사이로 지나가고 울타리는 한 개의 소품이 아니라 정원/땅의 경계다. 울타리에는 접근할 틈이 있다. | 세 정원에 둘레형 조각과 열린 출입구를 유지하고 충돌 모형도 같은 위치로 만든다. 길 가장자리에 불규칙한 잔디를 둔다. |
| 같은 영상, 18초 | 물가와 우물 주변의 돌·나무·녹지는 물의 가장자리를 만든다. | 연못 앞의 갈대·돌·나무·벤치를 묶고 벤치는 길가에서 연못을 보도록 둔다. |
| 원작 제공 사진 `1000038226`·`1000038228` | 집은 흙길을 향하고 울타리는 집 주변 대지 경계에 이어지며 통행 구멍이 있다. 통·상자·작업 재료는 건물 옆에 있다. | 상점의 짐은 대응 상점 앞/옆으로, 여관의 마차·상자는 출입 쪽으로, 집 주변 장식은 전면 마당으로 모은다. |
| 새 마을의 창작 계획 | 동선은 광장·상가·여관·주택을 잇고 휴게/시장/종교 공간은 각각 용도가 드러난다. | 외딴 장식은 제거하거나 가까운 건물/나무/길에 다시 붙인다. 건물에서 큰 길까지 잔디로 남는 구간은 보행 접근 관점에서 별도로 검수한다. |

`milles_garden.json`의 `anchor`는 대상 물체 ID·길 번호(`road_0`~`road_6`)·숲 구역, `role`은 사용하는 이유, `basis`는 관찰한 배치 패턴인지 새 마을 구성인지 나타낸다. 에셋 하나하나의 관계를 독립 좌표로 보존한다. `audit_milles_map_assets.py`는 관계 대상 존재, 물체 간 거리, 모든 벤치의 길 접근 거리, 정원 울타리와 충돌 발판을 검사한다. 이 수치 검사는 화면의 아름다움을 보증하지 않는다. 정면/측면이 겹치는지, 집의 입구가 실제로 길로 이어지는지는 여러 시점 렌더를 함께 판독한다.
