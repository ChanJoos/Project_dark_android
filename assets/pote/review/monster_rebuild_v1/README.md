# 포테의 숲 몬스터 원작 참조 리빌드 v1

이 경로는 기존 v0.4 생성물과 분리된 새 후보 작업입니다. 기존 v0.4의 168장은 참조 이미지로 사용하지 않습니다.

## 진행

- 확정 요구: 종/색상형마다 대기 4방향 + 걷기 4방향 + 공격 4방향, 총 12개의 개별 이미지.
- 현재 생성: 라이칸스로프 12개.
- 다른 13종: 아직 미완료.
- 기준 자료: [`lycanthrope_review.md`](lycanthrope_review.md), [`lycanthrope_manifest.csv`](lycanthrope_manifest.csv).
- 아직 APK에 적용하지 않았습니다.

## 사실과 생성 후보 구분

원작 참고 스크린샷에서 보이는 갑옷 늑대인간의 직립 실루엣, 짙은 갑옷, 은색 판금, 붉은 천, 한손 검을 디자인 기준으로 삼았습니다. 정면/후면의 네 방향과 걷기·공격 모션은 원작 프레임에서 확인하지 못해 새로 만든 후보입니다. 따라서 이를 원작 원본 또는 수락 완료라고 표기하지 않습니다.
