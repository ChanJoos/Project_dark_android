# 포테의 숲 몬스터 원작 참조 리빌드 v1

이 경로는 기존 v0.4 생성물과 분리된 새 후보 작업입니다. 기존 v0.4의 168장은 참조 이미지로 사용하지 않습니다.

## 확정 요구와 현재 상태

- 확정 요구: 종/색상형마다 대기 4방향 + 걷기 4방향 + 공격 4방향, 총 12개의 개별 이미지.
- 전체 대상은 레드/그린/퍼플/실버 팜팻, 트랜트, 앤트라이온, 놀, 울프라이더, 라이칸스로프, 앤트자이언트, 은빛늑대, 갈색/검은색 포테의 정령, 자이언트 맨티스의 14개 종/색상형입니다.
- 이전 기준에서 라이칸스로프 12개는 사용자가 시각 승인했습니다. 2026-09-29 추가 작업으로 팜팻 네 색상형 48개와 트랜트 9개 후보를 만들었습니다. 이후 사용자가 제공한 기본 외형 시트가 보이는 종의 idle 기준을 supersede합니다. 트랜트 idle 후보 4개는 이 시트로 대체할 대상으로 표시했고, 해당 idle을 새로 디자인하지 않습니다. 다른 후보는 아직 사용자 승인/게임 프레임 QA 전입니다. 현 상태는 manifest를 따릅니다.
- 직전 작업 회차에서 120개라고 보고했으나, 현재 저장소를 다시 확인한 결과 그 파일들은 체크아웃에 없습니다. 추적 가능한 결과로 계산하지 않으며 상태를 저장소 기준 12개로 정정합니다.
- 원격 작업 브랜치도 확인했습니다. 폐기 지시된 v0.4 168장 묶음은 `codex/lycanthrope-reference-grounded-assets`에 남아 있으나 새 디자인 입력에서 제외합니다. 다른 미병합 Pote 브랜치에는 보라 팜팻의 대기 4장·구르기 공격 4장 prototype이 있지만 걷기 프레임이 없고 원작 추출물이 아니어서 168장 완료 수량에 넣지 않습니다.
- 네이버 이미지 검색에서 포테 숲 실제 플레이 화면을 보존했습니다. 화면 속 보라 토끼형 및 나무형 개체는 각각 팜팻/트랜트 후보이며 이름표가 안 보여 미확정입니다. 새 PDF 두 개와 영상 두 개에서는 별도의 종별 sprite/frame을 확인하지 못했습니다.
- 기준 자료: [`source_audit.md`](source_audit.md), [`monster_artwork_manifest.csv`](monster_artwork_manifest.csv), [`lycanthrope_review.md`](lycanthrope_review.md), [`lycanthrope_manifest.csv`](lycanthrope_manifest.csv).
- 후보 이미지는 미리보기·개별 PNG 검수와 사용자의 시각 승인을 거치기 전 APK에 넣지 않습니다.

## 사용자 지정 기본 외형 기준 (2026-09-29 최신 지시)

- 사용자가 추가한 세 기본 외형 시트가 보이는 몬스터의 새 기준입니다. 이 시트에 보이는 몬스터는 기존 기본 외형을 유지하고 **걷기 4방향과 공격 4방향만 추가**합니다. 이미 있는 대기 모습을 다시 디자인하거나, 앞서 만든 후보 57장을 이 시트 기반 결과인 것처럼 간주하지 않습니다.
- 시트와 식별 한계는 [`source_capture/user_idle_bases/README.md`](source_capture/user_idle_bases/README.md), 출처/근거 내역은 [`source_audit.md`](source_audit.md), 파일별 시트/종 연결은 [`idle_base_reference_map.csv`](idle_base_reference_map.csv)를 봅니다.
- 갈색 사슴형→갈색 포테 정령, 흰 늑대형→은빛늑대, 나무형→트랜트, 초록 사마귀형→자이언트 맨티스는 외형에 따른 잠정 식별입니다. 가운데 두 벌레 행은 앤트라이온/앤트자이언트 중 어느 쪽인지 확인 전까지 이름을 임의로 붙이지 않습니다. 방향 셀 순서와 원본 게임 출처도 아직 확인되지 않았습니다.
- 이 시트들은 개별 투명 PNG 결과물이 아닙니다. 대기 프레임을 게임용으로 분리·정렬하는 작업과 걷기/공격 생성은 별도 상태로 기록합니다. 현재 manifest의 99 미완료 항목은 미완성 출력 경로 수이지, 전부 대기 외형을 새로 생성해야 한다는 뜻이 아닙니다.

## 사실과 생성 후보 구분

원작 참고 스크린샷에서 보이는 갑옷 늑대인간의 직립 실루엣, 짙은 갑옷, 은색 판금, 붉은 천, 한손 검을 해당 종의 디자인 기준으로 삼았습니다. 캡처에 없는 나머지 방향 및 걷기·공격 모션은 생성 후보입니다. 다른 종은 종별 원작 외형을 임의 추정하지 않습니다. 원작 프레임 또는 미검수 이미지를 원작 원본·수락 완료라고 표기하지 않습니다.

![포테 숲 후보 식별을 위해 원본 플레이 화면에서 자른 영역](source_capture/pote_woods_2011_creatures.jpg)

위 화면은 환경/실루엣 출처 후보이며, 그 자체를 개별 스프라이트나 수락된 아트로 간주하지 않습니다.


## 현재 파일 상태와 다음 작업 (2026-09-29)

- 완료 아트 수락 상태: 라이칸스로프 12장은 사용자가 시각 승인했습니다. 게임 크기/앵커 등 기술 QA는 별도입니다.
- 2026-09-29 선행 생성 이력은 팜팻 48장과 트랜트 9장입니다. 사용자가 지금 제공한 기준 시트로 만든 결과는 아닙니다. 새 시트가 제시된 뒤 트랜트 idle 4장은 사용자 시트로 교체 대상으로 표시했습니다. 나머지 53장은 승인된 완성본이 아닙니다.
- 최신 manifest 상태: 후보 53, 사용자 시트로 대체될 트랜트 idle 4, 종/행 매핑이 미확정인 기본 시트 8, idle 분리 대기 12, 기타 미생성 76, 트랜트 공격 상태 미확정 3, 라이칸스로프 시각 승인 12.
- 따라서 미완료 개별 출력 경로는 99개이며, 그중 20개 idle은 새 외형 생성이 아니라 사용자 시트에서 분리/정렬할 대상입니다. 트랜트 idle 후보 4개는 별도로 새 시트 기준으로 교체해야 합니다.
- 다음은 기본 시트와 로스터의 종/방향 매핑을 확정하고, 지정된 기본 외형을 보존해 걷기/공격 4방향을 추가하는 일입니다. 사용자가 준 기본 외형을 새로 그리지 않습니다. 종 연결이 불확실한 벌레 두 행은 이름을 임의로 붙이지 않습니다.
- 이미지 생성 서비스가 HTTP 429 사용량 한도를 반환했습니다. 응답의 재설정 시각은 2026-09-29 22:57:28 UTC (한국 시간 2026-09-30 07:57:28)입니다. 한도 전에는 새 모션 생성이 막혀 있습니다.
- 검수 전 후보는 APK에 넣지 않습니다. 확정 목록과 경로는 `monster_artwork_manifest.csv`, 사용자 기본 시트 및 잠정 연결은 `source_capture/user_idle_bases/README.md`와 `idle_base_reference_map.csv`를 따릅니다.


## 2026-09-29 — 생성 후보의 테스트 APK 등록

- 사용자가 생성 한도 해제를 기다리지 않고 현재 생성된 몬스터 이미지로 게임 등록과 APK 제작을 요청했습니다. 이 요청은 테스트 후보를 APK에 넣지 않는 기존 대기 조건을 **이번 테스트 빌드에 한해 대체**합니다. 시각 승인이나 원작 정사 지정으로 해석하지 않습니다.
- 현재 idle/walk/attack 4방향 12장 모두 있는 세트는 팜팻 보라/빨강/초록/실버와 라이칸스로프, 총 5종 × 12 = 60장입니다. 런타임 등록은 이 5종만 허용하고, 강력한 3종은 제외합니다.
- 트랜트는 idle 4 + walk 4 + attack NW 1만 있으므로 미등록입니다. 그 외 새 세트가 완성되지 않은 종도 미등록이며, 없는 방향/동작은 임의로 채우지 않습니다.
- 예전 16개 테스트 identity에 연결했던 `monster_test_v04` 런타임 포즈 매핑과 production 복사본은 APK 입력에서 제거합니다. 기존 review/concept 자료는 새 리빌드의 참조로 쓰지 않으며 보존 이력으로만 둡니다.
- 60개 생성 소스 PNG와 SHA-256은 이 디렉터리의 `sprites/` 및 `monster_artwork_manifest.csv`에 보존합니다. 패키지용 PNG는 `assets/pote/production/pote_monsters_generated_v1/sprites/` 아래 48×48 투명 프레임으로 정규화하고, 알파 실루엣 최대 높이를 30px로 맞춰 ground anchor를 정렬합니다. 프레임/앵커 수치는 테스트 씬 전용입니다.
- 프레임별 PNG는 idle/walk/attack 및 NW/NE/SW/SE 상태를 바꾸는 대표 포즈 한 장입니다. 다중 프레임 걷기·공격 루프는 포함하지 않습니다. AI의 정지/추적/근접 공격 상태 전환과 렌더 포즈 교체는 앱 동작으로 별도 검사합니다.
- CI에서 정확한 코드 SHA의 빌드·60포즈 렌더 테스트·APK 내부 에셋을 확인하고 결과를 `PROJECT_STATE.md`에 남깁니다. 실제 기기 검증과 신규 4색 팜팻 후보의 사용자 시각 수락은 별도 대기입니다.
