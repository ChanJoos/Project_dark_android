## 2026-09-29 사용자 제공 기본 외형 시트 추가

사용자는 이번 세 장을 비라이칸 몬스터들의 기존 기본 외형으로 지정하고, 해당 외형을 유지한 채 이동/공격 모션만 추가하라고 정정했습니다. 기존 생성 후보를 전부 같은 기준으로 만들었다고 간주하지 않습니다. 실제로 팜팻/트랜트 57 후보는 이 세 장을 입력으로 생성한 결과가 아닙니다. 따라서 이 후보를 승인된 기본 외형으로 이어 붙이지 않습니다.

- 원본 바이트를 `source_capture/user_idle_bases/`에 보존했습니다. 업로드 이름은 `.png`였지만 파일 시그니처는 JPEG라 `.jpg`로 저장했고 바이트는 변경하지 않았습니다. 체크섬, 보이는 내용, 추정 식별과 한계는 [기본 외형 시트 색인](source_capture/user_idle_bases/README.md)에 기록했습니다.
- `1000057381.jpg`: 4개 방향으로 보이는 갈색 뿔 달린 사슴형. 갈색 포테의 정령일 가능성이 높지만 시트에 이름표가 없습니다.
- `1000057379.jpg`: 4개 방향으로 보이는 흰/은빛 늑대형. 은빛늑대일 가능성이 높지만 시트에 이름표가 없습니다.
- `1000057376.jpg`: 네 줄에 각 네 방향 개체가 있습니다. 나무형은 트랜트, 초록 사마귀형은 자이언트 맨티스일 가능성이 높습니다. 가운데 두 벌레 줄은 앤트라이온/앤트자이언트 후보이나 줄-이름 대응을 확인하지 못했습니다.
- 셀별 방향명, 게임 원본 출처 여부, 투명 배경, 개별 프레임 경계·크기·발 앵커는 확인되지 않았습니다. 사용자 기준 이미지가 있는 몬스터의 대기 모습을 새로 디자인하지 않습니다. 기본 이미지를 보존하고 해당 외형에 맞춘 4방향 걷기와 공격 모션만 추가합니다. 개별 대기 PNG 출력이 필요하면 원본 시트에서 별도 분리/정렬한 결과로 처리하며 새 외형을 그리지 않습니다.
- `idle_base_reference_map.csv`에 시트별 가시 행과 잠정 종 연결을 기록했고, `monster_artwork_manifest.csv`에는 해당 idle 행의 원본 경로와 현재 처리 상태를 표시했습니다. 99는 현재 개별 출력 경로에 미생성/미확정으로 남은 파일 수이며, 99개의 새 외형을 처음부터 그리라는 뜻은 아닙니다. 기본 시트의 종/방향 매핑과 프레임 분리 상태를 함께 확인해야 합니다.

## 미해결

- 라이칸스로프 외 대부분 종의 실제 게임 픽셀 외형을 식별할 수 있는 원본 이미지/영상이 부족합니다. 현재 보존된 캡처에서 트랜트 및 보라색 팜팻으로 보이는 두 개체만 후보로 관찰했습니다.
- 대부분의 종에서 원작 4방향 idle/walk/attack 프레임은 확인되지 않았습니다.
- 회고 글의 외부 이미지 주소는 현재 제공된 검색/브라우저 환경에서 이미지 파일로 열리지 않았습니다. 이미지가 다시 확보되기 전에는 텍스트 설명을 근거로 한 그림을 `CANDIDATE`로만 기록하고 원작 복원·시각 승인이라고 부르지 않습니다.
- 기존 v0.4의 atlas, crop, 프레임은 새 생성의 입력 또는 정답 비교 기준으로 사용하지 않습니다.

위 마지막 문단은 원본 자료 감사 당시의 초기 상태 기록입니다. 2026-09-29 후속 생성 상태는 작업 manifest가 최신 기준입니다. 기존 생성 이력은 라이칸스로프 시각 승인 12장, 팜팻/트랜트 후보 57장입니다. 사용자 기본 외형 시트를 새 기준으로 연결한 뒤 트랜트 idle 4장은 해당 시트로 대체 대상으로 표시했습니다. manifest 최신 상태는 팜팻/트랜트 원본 후보 53장, 사용자 기준으로 supersede된 트랜트 idle 4장, 기본 시트 참조 20장(이 중 벌레 8장은 종 매핑 미확정), 미생성 76개 및 미확인 공격 소스 3개입니다. 99개 미완성 출력 경로 중 20개는 사용자가 준 idle 시트에서 분리해야 하며, 이 숫자는 99개의 새 외형을 생성하라는 뜻이 아닙니다. 후보 PNG는 64×64 프레임/앵커 QA와 사용자 승인을 통과하지 않았습니다. 별도 8장 prototype과 폐기된 v0.4 168장은 이번 디자인 입력 및 완료 수량에서 제외합니다.
