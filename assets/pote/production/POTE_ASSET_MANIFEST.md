## Spatial grammar
1. forest boundary -> dense large canopy -> understory -> groundcover
2. walk corridor -> bare soil/path -> sparse groundcover -> encounter pocket
3. stream -> water body -> bank transition -> stream rock -> moisture vegetation -> canopy
4. encounter pocket -> readable open floor -> peripheral blockers -> continuation/escape corridor
5. transition -> corridor width change -> landmark vegetation/rock cluster -> portal
